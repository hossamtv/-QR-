شرح برنامج توليد رموز QR (QR Code Generator)
📌 نظرة عامة
البرنامج هو أداة ويب لتوليد رموز QR مخصصة، تتيح للمستخدم إنشاء رموز QR بتصاميم وألوان مختلفة وربطها بروابط أو نصوص محددة.
🗂️ تبويبات البرنامج الثلاث
1️ تبويب Color (اللون)
يتيح تخصيص ألوان الرمز:
Dots Color (لون النقاط): يمكن اختيار لون النقاط الداكنة في الرمز (الافتراضي أسود)
Background (الخلفية): يمكن اختيار لون خلفية الرمز (الافتراضي أبيض)
2️ تبويب Style (النمط/الشكل)
يتيح تخصيص شكل الرمز بالكامل:
Dots Style (نمط النقاط): اختيار بين Dots (نقاط)، Rounded (مدورة)، Square (مربعة)
Marker Border (إطار العلامات): اختيار بين Circle (دائرة) أو Square (مربع)
Marker Center (مركز العلامات): اختيار بين Dot (نقطة) أو Sq (مربع)
3️⃣ تبويب Link (الرابط)
Enter URL or Text: حقل لإدخال الرابط أو النص المراد تحويله إلى رمز QR
