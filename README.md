Explanation of the QR Code Generator program
📌 Overview
The program is a web tool for generating custom QR codes, allowing the user to create QR codes with different designs and colors and link them to specific links or texts.
🗂️ The program's three tabs
1️ Color tab
This tab allows you to customize the icon colors:
Dots Color: You can choose a dark dot color for the icon (default is black)
Background: You can choose the background color for the icon (default is white)

2️ Style tab
This allows you to fully customize the icon's shape:
Dots Style: Choose between Dots, Rounded, and Square
Marker Border: Choose between Circle or Square
Marker Center: Choose between Dot or Square
